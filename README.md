# Reproducible gene expression patterns associated with schizophrenia: code and data

Figure scripts, figure data, supplementary tables and the provenance tables for the paper.

## Reproducing the figures

The figure tables, the code and the manifests are all in this repository. Starting from a clone:

```
./reproduce_figures.sh            # checks each file's sha256 against its manifest, rebuilds every figure
```

`figures/scripts/verify_data.py` checks the tables and `figures/scripts/rebuild_all.py` redraws the figures
(`--list` shows which figures and scripts there are; they are listed in `figures/scripts/FIGURES.tsv`). Requirements:
Python 3 with numpy, pandas, scipy, matplotlib and Pillow. Every figure is regenerated by a script here; the images are generated and are not tracked.

What the repository contains for each figure:

- `figures/scripts/`: one script per main or extended figure (`figkit.py` holds shared style and saving);
  `figures/results/`: the SVG and PNG with a `*_meta.json` giving the sha256 of every input and output (generated, not
  tracked);
  `figures/data/`: the tables those figures read.
- `supplementary_notes/<topic>/`: everything for one supplementary note, in a folder named for its topic (no note numbers in folder, script or figure names, so the notes can be reordered): `build_*.py`, `data/` and `results/`. A note
  dropped from the paper is removed by deleting its folder; the main and extended figures do not depend on any note.
  Tables read by more than one figure are in `figures/data/`.
- Each data folder has a `MANIFEST.tsv` with the sha256 of each table and the `# script:` and `# source:` lines from its
  header, which name the analysis script that produced it and that script's inputs. `figures/data/READS.tsv` lists which
  figure reads which table.
- `figures/CAPTIONS.md`: what each figure is, how to read it, what it shows.

`DATA_NEEDED.tsv` lists the external data the tables were built from (source, access, accession, version, and what in this repository derives from it); `DATA_NEEDED_gaps.tsv` lists what is not yet recorded, and `DATA_NOT_IN_REPOSITORY.tsv` the files cited in the source comments that are not included. `tools/check_source_comments.py` checks that every path cited in a source comment is in the repository or marked as not included.

Only the tables the figures read are kept here. The analyses that produce them, and everything else from the project,
are in the analysis repository (`schizophrenia-transcriptome-replication`); the raw expression data are public
(GEO, Gemma, GTEx, CELLxGENE and the cited studies), and some datasets are available only under controlled access from
their providers.

## Updating the figure data

When new tables are delivered to a folder (`$DELIVERY` below):

```
SZ_FIGURE_DATA=$DELIVERY python3 figures/scripts/rebuild_all.py --audit
python3 figures/scripts/sync_figure_data.py --source $DELIVERY
python3 figures/scripts/rebuild_all.py
python3 figures/scripts/verify_data.py
```

The first step rebuilds from the delivery folder and records which files each figure reads; the second copies exactly
those files into `figures/data/` (or into `supplementary_notes/<note>/data/` when only that note's figures read the file)
and rewrites the manifests; the third checks that the repository copy rebuilds; the fourth checks the files against the manifests.

## Other folders

- `supplementary/`: supplementary tables and data (tab-separated, `#` headers), provenance in `supplementary/provenance/`.
